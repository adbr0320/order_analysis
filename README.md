# Пакетный анализ заказов

Итоговая работа по модулю "Основы Python" (Нетология, курс "Системный аналитик").

Скрипт проходит по всем CSV-файлам в папке `data/`, по каждому берёт только доставленные заказы (`status == 'Delivered'`) и считает выручку, средний чек и количество заказов. Результат по всем файлам сохраняется в `reports/summary_report.csv`, ошибки пишутся в `logs/errors.log`.

## Запуск

```bash
pip install -r requirements.txt
python run.py
```

## Структура

```
order_analysis/
├── data/          # входные CSV
├── reports/       # summary_report.csv
├── logs/          # errors.log, в нём только ошибки последнего запуска
├── src/
│   └── analyzer.py   # класс OrderAnalyzer
├── config.py      # пути, имена файлов, колонки и статус для фильтра
├── run.py         # точка входа
└── requirements.txt
```

## Данные

`order_10000.csv` и `order_100000.csv` взяты из датасета [Synthetic Order Records: 10K to 10M Records](https://www.kaggle.com/datasets/swainproject/synthetic-order-records-10k-to-10m-records) (CC BY 4.0).

Ещё три файла испорчены специально, чтобы проверить устойчивость:

| Файл | Что с ним не так |
|------|------------------|
| `orders_broken_amount.csv` | в `total_amount` текст ("не указано", "12,99") |
| `orders_wrong_columns.csv` | другой разделитель и другие колонки |
| `orders_empty.csv` | пустой файл |

## Ограничения

- Суммы в датасете в трёх валютах (USD, EUR, GBP, примерно поровну), а выручка по заданию считается простой суммой `total_amount`. Для реального отчёта её нужно либо пересчитывать в одну валюту, либо считать отдельно по каждой.
- Проверяются только колонки, нужные для расчёта (`status` и `total_amount`). Если в файле не хватает, например, `notes`, он всё равно обработается.
